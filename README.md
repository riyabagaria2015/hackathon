# hackathon

## Run

With [uv](https://docs.astral.sh/uv/) installed:

```bash
uv run python main.py
```

Day 1 adds the async interruption demo at `src/fake_interruption_engine.py`. After that file exists, run:

```bash
uv run python src/fake_interruption_engine.py
```

Python **3.11+** is required (`requires-python` in `pyproject.toml`).
